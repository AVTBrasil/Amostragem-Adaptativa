# Amostragem-Adaptativa

[![Open in Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/AVTBrasil/Amostragem-Adaptativa/blob/feature/llm-judge/avaliacao_colab.ipynb)

O notebook de avaliação clona a branch `feature/llm-judge` no Colab. Selecione GPU T4 e monte o Google Drive quando solicitado. Checkpoints e resultados serão salvos em `Meu Drive/Amostragem-Adaptativa/saidas_juiz/`.
Esse é um projeto que tenta inferir se a resposta de um problema é verdadeira ou falsa através de duas redes neurais. A primeira irá responder a pergunta do modelo e o segunda 'judge' ficará responsável por avaliar essa resposta.
